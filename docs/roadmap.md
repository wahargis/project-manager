# Roadmap

Project Manager is a working system with an honest open tail.

**Shipped**

- Typed knowledge-graph store with versioned migrations.
- DAG engine: topological sort, impact-sorted next-phase selection, stagnation detection.
- Truth maintenance: confidence propagation, contradiction suspension, orphan/staleness analysis.
- CLI, MCP stdio server with 37 tools, and embedded web dashboard.
- Full-text and graph-assisted search.

**In progress**

- Causal-backbone traversal edges.
- CLI mirrors and project-scoped search polish.

**Planned / experimental**

- Auto-transition and review-gate orchestration.
- Richer long-horizon session context and handoff generation.
- Migration of v2 JSON reference data into typed v3 state.

Historical planning notes are preserved under `docs/reference/`.
